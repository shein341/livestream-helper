# 主播提现规则与常见问题

## 一、适用范围
本规则适用于平台内所有已完成实名认证的主播账号，包括个人主播、公会主播及机构签约主播。若主播同时绑定多个结算主体，以当前开播账号绑定的结算信息为准。

## 二、提现前置条件
1. 主播账号需完成实名认证，且实名姓名与收款账户信息一致。  
2. 收款账户需为本人银行卡，不支持对公账户或他人代收。  
3. 账号当前不可处于封禁、冻结、限制提现等风控状态。  
4. 若存在未完结退款、投诉争议单，平台可临时延后提现审核。  

## 三、提现金额与次数限制
1. 单次最低提现金额为 100 元。  
2. 单日最多可提交 3 次提现申请。  
3. 不同等级主播的单日累计提现上限不同，以主播后台“资金中心”显示为准。  
4. 活动奖励、违约金扣款、补贴冲抵等特殊资金按活动规则单独结算。  

## 四、审核与到账时效
1. 常规提现申请：审核通过后预计 T+1 个工作日到账。  
2. 命中风险策略的申请：进入人工复核，预计 1-3 个工作日完成。  
3. 法定节假日、银行通道维护期间：到账时效顺延，不计入超时异常。  
4. 若支付通道异常，平台会在公告页同步进展并提供预计恢复时间。  

## 五、驳回原因说明
常见驳回原因包括但不限于：
- 实名信息与银行卡信息不一致  
- 账户命中异常交易或异常登录风控规则  
- 提现申请资料不完整或结算账单存在争议  
- 当日提现次数超限或金额超过账户等级上限  

## 六、主播操作指引
1. 进入主播后台，点击“资金中心 - 我要提现”。  
2. 确认可提现金额、到账银行卡、预计到账时效。  
3. 输入提现金额并提交申请。  
4. 在“提现记录”页查看审核状态：待审核、审核通过、驳回、已到账。  

## 七、申诉与补件
1. 若提现被驳回，主播可在 7 日内根据驳回原因补齐材料并重新提交。  
2. 若对风控判定有异议，可在工单中心发起申诉并上传订单截图、聊天记录、物流凭证等辅助材料。  
3. 平台将在 5 个工作日内反馈申诉结果，并在工单内说明判定依据。  

## 八、常见问题（FAQ）
### Q1：为什么我昨天提现，今天还没到账？
A：请先确认是否为工作日，以及是否命中人工复核。若状态显示“审核通过”但超过预计时效未到账，请提交工单并附提现单号。

### Q2：为什么显示可提现金额和我预估不一致？
A：可提现金额会扣除退款、违约金、活动冻结金等项目，最终以“资金明细”账单为准。

### Q3：提现失败后可以立即重提吗？
A：可以。请先根据驳回原因完成补件或修正信息后再提交，避免重复失败触发额外风控。
